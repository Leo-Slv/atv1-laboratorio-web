# Atividade 1 – Rotas e navegação no Next.js

Gestão de alunos, disciplinas e matrículas (Next.js + TypeScript + App Router, em `src/`).

```bash
npm install
npm run dev
```

- Rotas: `/`, `/alunos`, `/alunos/[ra]`, `/alunos/novo`, `/disciplinas`, `/matriculas`, `/matriculas/nova`
- Estado compartilhado via Context; cadastros persistidos no `localStorage`. Sem banco de dados ou API.
